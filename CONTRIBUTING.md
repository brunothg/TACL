# Contributing Guidelines

Thank you for your interest in contributing to this project!
To protect the legal integrity and code quality of this repository, all external pull requests must meet the requirements below.

## 1. AI Policy
We do **not** accept code or assets generated by AI.

* All contributions must be written and understood by a human author and follow [Codeberg's LLM policy](https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html).
* You will be required to explicitly attest to this in the Pull Request checklist.
* Pull requests suspected of containing unvetted AI-generated output will be closed without merging.

---

## 2. Mandatory Commit Requirements (`-S` and `-s`)
Every commit in a pull request must include **both**:
1. **A cryptographic signature (`-S`)** proving your identity.
2. **A DCO sign-off line (`-s`)** certifying you have the legal right to submit the code under the [Developer Certificate of Origin](https://developercertificate.org/).

Pull requests with unsigned or non-signed-off commits will be blocked.

## 3. Submitting a Pull Request
1. Fork the repository and create a new branch from `main`.
2. Keep pull requests focused on a single bug fix or feature.
3. Fill out the Pull Request template completely and check all required attestation boxes.
